# signature-assets

Icons for my email signature. Gmail can't embed images from my computer, so
they're hosted here and linked by their raw GitHub URLs.

| File | Raw URL |
|---|---|
| `github.png` | `https://raw.githubusercontent.com/maniesh-lab/signature-assets/main/github.png` |
| `linkedin.png` | `https://raw.githubusercontent.com/maniesh-lab/signature-assets/main/linkedin.png` |

The repo has to stay public, or the icons stop showing in sent emails.
